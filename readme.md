# Ration Distribution System (RDS) - Transparent PDS Management

An end-to-end digital solution for the Public Distribution System to eliminate black marketing, ensure transparency, and create accountability between Admin, Shopkeepers, and Citizens.

🔗 **Live Repository:** https://github.com/rutujakolhe290/RDS_Project

## 📸 Project Overview
The traditional ration system suffers from manual record keeping, lack of visibility, and malpractice. This system digitizes the complete flow from government stock allocation to citizen distribution with permanent receipts, live stock tracking, and complaint redressal.

## ✨ Key Features

### 1. Admin Dashboard
- Centralized monitoring of all Fair Price Shops (SHOP001, SHOP002, SHOP003)
- Live stock indicators for Wheat, Rice, and Sugar with low-stock alerts (< 20kg)
- Stock addition with automatic shop synchronization
- Permanent Citizen Receipts archive with advanced search
- Suspicious Activity & Black Marketing Detection System
- Complaint Management & Admin Activity Log

### 2. Shopkeeper Dashboard
- Shop-specific stock visibility
- Citizen distribution with Aadhar verification
- Automated entitlement calculation
- Distribution history

### 3. Citizen Portal
- Personal entitlement view
- Distribution status tracking
- Complaint submission with image proof
- Digital receipt access

## 🛠️ Technology Stack
- **Frontend:** HTML5, Tailwind CSS, JavaScript
- **Backend:** Flask (Python)
- **Authentication:** Aadhar + OTP based session
- **Database:** In-memory + SQLite support
